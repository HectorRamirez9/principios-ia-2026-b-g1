### Formación virtual

La formación virtual facilita el proceso académico mediante herramientas tecnológicas y plataformas como **Moodle**, permitiendo la interacción entre estudiantes y profesores sin depender del mismo espacio físico.

Aspectos destacados:

- Favorece la conexión entre estudiantes y profesores.
- Facilita el desarrollo del proceso académico.
- Promueve el apoyo colaborativo.
- Requiere responsabilidad de todos los participantes.
- Reduce las limitaciones relacionadas con el espacio físico.
- Puede presentar riesgos si no existe compromiso o no se alcanzan los resultados académicos esperados.
